A Futuriza, além de resolver a vida das pessoas no trabalho e auxiliar na adaptação das empresas a este novo tempo, busca de forma ampla solucionar questões como o tempo de deslocamento (casa/trabalho).
Na nossa proposta, tentamos entender a dor de ambos os lados: empresa e funcionário. Pelo ponto de vista da empresa, gerenciar todas essas pessoas e, ainda, cobrar resultados é um grande desafio. É aí que a Futuriza entra:
As salas virtuais da futuriza poderão ser personalizadas.
Todos que entrarem nas reuniões terão seus avatares e poderão interagir com lousas, quadros, painéis e a mesa.
Poderão fazer anotações e muitas outras interações, tudo de acordo com a necessidade de cada cliente, aprimorando as reuniões online tradicionais.
Não parando por aí, também desenvolvemos uma tela, pensando na acessibilidade.
Essa tela teria uma personalização voltada a:
    > Pessoas que possuem movimentos motores reduzidos.
    > Pessoas que necessitam de estímulos visuais específicos, como autistas.
A tela captaria os movimentos e, ajustando o hub e a sensibilidade, o usuário seria capaz de digitar com, quem sabe, a mesma velocidade de uma pessoa sem necessidades especiais.
Nossa última e não menos importante solução é o que chamamos de Task Market, uma plataforma para pessoas autônomas ou vinculadas a uma empresa.
Nessa página, o usuário será capaz de buscar cursos para se profissionalizar ou aprimorar suas skills, de forma dinâmica, coletando emblemas e subindo seu perfil de skills.
Do outro lado, as empresas poderão ficar de olho para futuras contratações ou, internamente, montar a melhor squad, combinando skills dos funcionários.
É uma forma simples de oferecer ao seu funcionário um ambiente mais progressivo e um ótimo filtro para o RH na hora da contratação.
Essa é a melhor e mais resumida descrição que poderíamos dar sobre nosso projeto: Futuriza
Para ter acesso a essas ferramentas após o atendimento foi pelo nosso bot, implementado via link no site, o usuário receberá uma senha, o qual terá acesso as nossas funcionalidades pagas, como o Task Market, usamos o código java script para validar as informações de login e na página de contato em caso de outras dúvidas que não tenha no FAQ da empresa, o Task Market foi desenvolvido em python uma grande parte, e o site 48% css e 46% html o restante em java script.
